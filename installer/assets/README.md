# Иконка Finance: исходный файл

Исходное изображение хранится здесь: `installer/assets/finance-icon.png`. Если будете менять знак, замените этот файл и оставьте имя прежним.

Требования к файлу (подходят и для замены текущего изображения):

- PNG, квадрат не меньше 1024 × 1024 px, цветной режим RGB или RGBA. Текущий файл — 1254 × 1254 px, RGB.
- Оставьте важные детали внутри центральных 80% изображения: Windows уменьшает значок до 16–32 px.
- Не используйте мелкий текст и тонкие линии.
- Прозрачный или однотонный фон подходит. Не добавляйте скруглённую рамку по краям: Windows может обрезать значок по системной форме.

Исходник уже создан и находится в `finance-icon.png`. Сборщик Windows автоматически создаёт из него многоразмерный `finance.ico` в staging-папке и подключает этот ICO к установщику и ярлыкам. Вручную создавать или хранить ICO рядом с исходником не нужно.
