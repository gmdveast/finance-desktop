# Финансовый журнал (Finance)

Локальное приложение для учёта личных финансов. Основной интерфейс работает в браузере, а данные хранятся в книге Excel на вашем компьютере. Телефон можно подключить отдельно через Syncthing и Obsidian Mobile.

> **Статус: стабильная версия 1.0.0 для Windows x64.** Finance хранит данные локально; регулярно создавайте проверяемую копию на отдельном носителе.

## Установка

1. Откройте [релизы Finance для Windows](https://github.com/gmdveast/finance-desktop/releases) и выберите последний стабильный релиз.
2. Скачайте `Finance-Setup-...-x64.exe` и запустите установщик. Node.js и npm отдельно устанавливать не нужно.
3. Откройте Finance из меню «Пуск». Приложение запустит локальный сервер и откроет страницу в браузере.
4. При первом запуске выберите **«Создать новую книгу»** или подключите существующую книгу Finance `.xlsx`. При подключении исходный файл не меняется: приложение проверит его и создаст рабочую копию.

Для существующей книги нужны листы «Операции», «Списки», «Баланс» и «Сводка». Максимальный размер файла для импорта — 50 МБ.

Инсталлятор не подписан издательским сертификатом, поэтому Windows может показать предупреждение SmartScreen. Скачивайте его только со страницы релизов Finance и сверяйте SHA-256 с файлом `.sha256`, опубликованным рядом с установщиком. Если сумма совпала и SmartScreen всё ещё блокирует запуск, в окне предупреждения выберите «Подробнее» → «Выполнить в любом случае». Если файл скачан из другого места или SHA-256 не совпадает, отмените запуск.

Для ручной проверки откройте PowerShell и выполните команду, подставив точное имя скачанного файла:

```powershell
Get-ChildItem "$env:USERPROFILE\Downloads\Finance-Setup-*-x64.exe" |
  Sort-Object LastWriteTime -Descending |
  Select-Object -First 1 |
  Get-FileHash -Algorithm SHA256
```

Команда проверяет последний скачанный установщик Finance в папке «Загрузки». Сравните значение `Hash` с хешем в скачанном рядом файле `.sha256`. Встроенное обновление Finance проверяет SHA-256 автоматически.

## Где находятся приложение и данные

- Программа и версии: `%LOCALAPPDATA%\Programs\Finance`
- Книга, настройки и кэш курсов: `%LOCALAPPDATA%\Finance\data`
- Рабочая книга по умолчанию: `%LOCALAPPDATA%\Finance\data\uchet_povsednevnyh_finansov.xlsx`
- Автоматические копии книги: `%LOCALAPPDATA%\Finance\data\backups`
- Папка обмена с телефоном: `%LOCALAPPDATA%\Finance\Finance Sync`

Точные пути также отображаются в Finance. Удаление программы не удаляет книгу и другие пользовательские данные.

Чтобы открыть папку данных в Проводнике Windows, вставьте `%LOCALAPPDATA%\Finance` в адресную строку Проводника.

Finance создаёт локальную резервную копию перед каждой записью и хранит последние 30 копий на этом же компьютере. Это не защищает от отказа диска. В «Настройки» → «Копия на другом носителе» можно сохранить recovery ZIP, проверить его и выполнить пробное восстановление. ZIP содержит всю финансовую книгу и не зашифрован: храните его на защищённом носителе. Для защиты от потери компьютера сохраните и проверьте архив на другом физическом диске.

## Работа с книгой

Excel-книга — источник финансовых данных, а Finance — единственный поддерживаемый писатель. Не открывайте рабочую книгу в Excel для редактирования, пока Finance запущен. Не храните книгу в сетевой или синхронизируемой папке и не запускайте две копии Finance с одной книгой.

Finance автоматически создаёт копию книги перед изменениями. В разделе «Настройки» можно открыть папку данных и восстановить выбранную локальную копию. Перед восстановлением Finance сохраняет отдельную страховочную копию текущей книги.

## Подключение телефона — необязательно

Для мобильного ввода нужны отдельные приложения Syncthing и Obsidian Mobile. Finance не устанавливает их автоматически.

1. В Finance откройте «Подключение телефона» и нажмите «Подготовить данные для телефона».
2. Настройте Syncthing на компьютере и телефоне и синхронизируйте показанную папку `Finance Sync` с хранилищем Obsidian на телефоне.
3. В Obsidian установите BRAT, добавьте beta-плагин `gmdveast/finance-capture` и включите Finance Capture.
4. Дождитесь синхронизации справочников и счетов, затем откройте форму Finance Capture в заметке.

Плагин создаёт операцию в очереди на телефоне. Компьютер импортирует её в Excel, когда он включён и папка синхронизирована. Если компьютер недоступен, операция остаётся в очереди. Плагин и desktop обновляются отдельно: плагин — через BRAT, приложение — из раздела «Настройки».

## Обновление и откат

В Finance откройте «Настройки» → «Проверить обновления». Перед установкой Finance скачивает установщик с GitHub и проверяет его SHA-256. Книга и настройки хранятся отдельно от версии программы. В меню «Пуск» есть команда «Откатить версию Finance».

Обновления beta-плагина Obsidian выполняются в BRAT и не меняют версию desktop-приложения.

## Приватность и ограничения

- Книга и операции не отправляются на сервер Finance. Syncthing синхронизирует только выбранную вами папку между устройствами.
- Desktop получает валютные курсы с сайта ЦБ РФ. Проверка обновлений связывается с GitHub только после нажатия соответствующей кнопки.
- Поддерживается Windows x64. Linux, macOS, совместное редактирование книги и несколько компьютеров-писателей не входят в текущую поставку.
- Для полного восстановления после потери компьютера нужна отдельная проверенная копия на другом физическом носителе. Мастер помогает создать и проверить архив, но пользователь должен сам выбрать носитель и убедиться, что файл сохранён именно там.

Сообщайте об ошибках, указывая версию Finance и шаги воспроизведения. Не прикладывайте рабочую книгу, recovery-архив, финансовые операции или runtime-файлы.

## Для разработчиков

Проверенная среда разработки — Windows и Node.js 24.15.0. При клонировании исходников загрузите submodule командой `git clone --recurse-submodules <URL-репозитория>` либо выполните `npm run setup:submodules`.

```powershell
npm ci
npm run qa
npm audit
```

Автоматические тесты используют синтетические книги из `tests/create-fixture.mjs`; не заполняйте их данными рабочей книги. Для сборки Windows-установщика требуется Inno Setup 6:

```powershell
npm run package:windows -- -AppVersion 1.0.0-beta.8 -UpdateChannel beta
```
